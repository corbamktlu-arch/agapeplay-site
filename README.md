# 🎵 Agape Play - Rádio Indoor

Sistema profissional de Rádio Indoor para lojas, academias, supermercados e empresas.

## 📡 Sobre o Projeto

O Agape Play é uma plataforma completa de rádio indoor que permite:

- Reprodução automática de playlists
- Avisos programados
- Locutor virtual
- Chamadas personalizadas
- Controle de volume inteligente
- Gerenciamento por painel administrativo
- Integração com Supabase

---

## 🚀 Tecnologias Utilizadas

- Vite
- React
- TypeScript
- Tailwind CSS
- Supabase
- Shadcn UI
